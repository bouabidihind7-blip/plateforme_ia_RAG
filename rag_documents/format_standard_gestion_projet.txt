Catégorie : Production
Q : Quelle est la conséquence si une commande nécessite une pièce dont les dimensions dépassent 300x300x400 millimètres ?
R : Si une commande nécessite une pièce dont les dimensions dépassent le volume d'impression maximal de 300x300x400 millimètres disponible sur les imprimantes FDM de l'atelier, elle est automatiquement redirigée vers une étude de faisabilité en impression SLS.

Catégorie : Production
Q : Quelle est la seule technologie de 3D Smart Factory capable de traiter des volumes supérieurs à 300x300x400 millimètres ?
R : L'impression SLS est la seule technologie de 3D Smart Factory capable de traiter des volumes plus importants que les dimensions maximales des imprimantes FDM.

Catégorie : Production
Q : Que se passe-t-il si un client signale une non-conformité sur une pièce reçue ?
R : Si un client signale une non-conformité sur une pièce reçue, la réclamation est transmise sous 48 heures au responsable production, Hamza Fassi.

Catégorie : Production
Q : Comment Hamza Fassi évalue-t-il la pièce retournée en cas de signalement de non-conformité ?
R : Hamza Fassi évalue la pièce retournée selon les mêmes critères que ceux du contrôle qualité interne, à savoir une tolérance dimensionnelle de 0.2 millimètre et l'absence de défauts de surface majeurs.

Catégorie : Production
Q : Quels sont les critères du contrôle qualité interne appliqués par Hamza Fassi lors d'un litige ?
R : Les critères du contrôle qualité interne appliqués par Hamza Fassi sont une tolérance dimensionnelle de 0.2 millimètre et l'absence de défauts de surface majeurs.

Catégorie : Production
Q : Quelle est la procédure de 3D Smart Factory si la non-conformité d'une pièce est confirmée ?
R : Si la non-conformité est confirmée, 3D Smart Factory procède au remplacement gratuit de la pièce avec une priorité de production.

Catégorie : Production
Q : Dans quel délai et sous quelle modalité la nouvelle pièce est-elle réimprimée en cas de non-conformité avérée ?
R : La nouvelle pièce est réimprimée en tête de file dans un délai maximal de 3 jours ouvrés, sans frais supplémentaire de livraison pour le client concerné.
